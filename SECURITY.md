# Reporting a security problem

Chompy holds a terminal on your own machines, so a flaw in it can matter. If you find one, please
don't open a public issue. Report it privately through GitHub's
[private vulnerability reporting](https://github.com/jeffarese/chompy/security/advisories/new), or by
email to [jeffarese@gmail.com](mailto:jeffarese@gmail.com).

Say what you found, which version it is in, and how to reproduce it. You'll hear back within a week.
Fixes ship in the next release, on GitHub and Google Play alike, and the advisory credits you unless
you'd rather it didn't.

A problem in Rex itself, the server, belongs with [Superlogical](https://www.superlogical.com).
